# FSA-Bench Project Page

This folder contains the project page for:

**FSA-Bench: Benchmarking Federated Survival Models**

## Files

- `index.html` — project page
- `css/style.css` — styling
- `js/script.js` — navigation and citation-copy interaction
- `assets/` — figures and favicon extracted/prepared from the paper

## GitHub Pages

For the simplest deployment, place the contents of this folder at the repository root:

```text
FSA_Bench/
├── index.html
├── css/
├── js/
├── assets/
├── README.md
└── ...existing research files...
```

Then enable GitHub Pages from:

**Settings → Pages → Deploy from a branch → main → /(root)**

The project page will then be served from the repository's GitHub Pages URL.
